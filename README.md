# NETWORKWALKS-ZOE-B083-WK2-PM2-FOOTPRINTING---RECONNAISSANCE-WITH-GHDB
# Project Overview
This repository details how reconnaissance and foot-printing can be achieved using a regular search engine. It shows the steps taken to access information that is accessible on the internet which can be useful to hackers for malicious intent, and simultaneously raises our awareness of how unguarded data left on the web due to carelessness or oversight can be accessible to anyone around the world.
# Project Objectives
1. Access www.exploit-db.com: The website that hosts GHDB.
2. Access Google Dorks through the GHDB (Google Hacking Database). N/B: Google dorks are search queries used with search operators that can pull sensitive information
3. Enter particular queries in the database to pull related dorks.
4. Enter dorks of interest in our search engine.
5. Access links that lead to these sensitive data.
6. Record findings.
